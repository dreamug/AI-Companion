## 新交流实验

入口 **http://127.0.0.1:4341/**，角色「小野·接话试聊」。只继承 4331 小野的人格配置，没有复制用户聊天、记忆或本次演示记录。交付时 messages、memories、runs、inbox、profile slots 和 conversation summaries 均为 0。人格按正常发布方法留存，当前 revision2；日额度 1,000,000 token。首次发送仍由用户确认原有外发说明。

该副本复用同一套稳定记忆，另开 `conversationExperiment`。正式入口强制关闭该实验，不会因为角色设置或环境变量把实验提示注入主 bot。

本轮只调整两点：

1. 打开已有分条及发送间隔。首条完整检查后立即发布；后续按长度等待 1.2至3 秒。等待属于发布阶段，不增加模型调用；插话或停止会取消尚未发出的气泡。
2. 在现有主生成上下文追加版本化交流指引：前面先回应具体内容，最后一条酌情提问、共鸣或留下看法；需要澄清也放在末条；忙碌、休息或不想细说时允许结束，不为续聊强行追问。人格和明确交流边界继续生效。

没有新增“接话 Agent”、风格评审调用、强制问号比例或新的记忆机制。问句位置由生成指引约束，不伪称程序已保证所有自然语言输出都满足。

重启新试聊：`npm run conversation:trial`，只操作 `local-data/conversation-turn-v1`。已存在目录会保留聊天与配置，不重复创建或重置角色。

- 全量 **52 文件、796/796** 通过；类型检查及隔离编译通过。随后 UI 旧候选按钮和新试聊发布设置修正后，相关 **36/36** 复查通过。

- 新实验测试验证：实验指引按 Run 捕获、稳定路径不注入、两项检查保持原次数及范围，以及首条检查后发布、间隔中取消保留已发送部分。
- 正式库升级过程中 **0 次模型调用**。另在合成库对现有 Grok 通路做两次真实聊天：设置称呼成功，清模型上下文后正确召回；完整回复约 7.29 秒、4.27 秒。没有向模型发送正式历史来做发布测试。

交流实验在实施前冻结 16 个输入及语义评判要求，基线/候选交替各运行一次，共 32 个回合，全部完成。首轮发现一条澄清问题放在前条，补的是通用人称问句位置规则，没有题号或主题分支；随后只复跑同一 16 题候选，全部完成。原 32 条输出及失败保留，未替换题目、修改预期或重复抽样挑结果。最终相邻气泡实测 **1200至3003 ms**。

**完成不等于陪伴向全通过。** 人工复核仍发现：致谢后有额外邀约、不同意见的中间段有确认式问句、平淡或疲惫时仍可能多问，以及角色条件式自述是否令人误会有真人生活。这些保留为试聊观察点，未把它们改计成正确；不继续围绕已知题加提示补丁。新实验需要用户判断自然程度，不能用一个合成通过率替代。

真实浏览器在合成副本发送了新的公园速写分享：先回应观察画画的感受，**1202 ms** 后再发末条问题；原两项检查均完成，无新事实入库。演示放在 4332，已关闭，没有把它写进 4341。浏览器最终停在 4341 的空白角色，分条和发送间隔均开启。

实验模型台账累计 **378,003 token / 450,000 上限**，初轮与复跑共用台账，没有重置失败费用；Grok 发布通路实测另有独立账本；浏览器额外一轮的真实 Run 与用量单独存档。原始资料在 `test-results/conversation-turn-v1/`，包括冻结计划及哈希、两轮结果、人工观察、模型账本、浏览器记录、空白状态和截图。
