## 生命周期与数据

- 独立 SpeechPort 不接管 Agent 循环、不创建新记忆；前端不能提交任意文本绕过来源检查。
- 请求截止 45 秒、最多 4000 字／10 MiB、单并发，不自动重试收费请求。
- 停止／新消息／遗忘／关闭页面释放播放资源；请求断开、来源变化或服务退出使远端调用取消。已经外发的文本及提供方可能已经完成的计费无法撤回。
- 普通音频不落盘，Blob 释放后不再播放，不纳入导出／备份。唯一主动保留的音频是固定合成诊断样本，不含私人聊天。
- 仅选择朗读的正文发送给 Fish Audio，Trace 只记字符、音频字节、耗时、配置、费用未知。Fish Audio 金额不混入 DeepSeek Token 预算，提供方远端留存／删除仍无额外保证。
