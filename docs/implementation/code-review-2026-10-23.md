## 3. 上线状态与边界

升级前创建了一致性备份，重启后核对消息数量和删除代数没有回退。SQLite 仍是单用户个人版，未新增公网访问、账号系统、租约或多实例设施。浏览器页面需刷新才能加载新的客户端代码，可先保留未发送草稿。
