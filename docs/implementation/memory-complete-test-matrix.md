# 记忆完整实现测试矩阵

日期：2026-10-24。状态：已执行本轮自动验收；实际结果、失败样本和未测范围见[完整验收报告](memory-complete-acceptance.md)。有限测试不能证明自然语言所有可能输入均正确，本轮以明确合同、组合边界、固定随机种子、独立题集和真实模型输出共同验收，不以 mock 回答冒充语义准确率。

| 维度       | 正向与反向用例                                                             | 验收依据                                 |
| ---------- | -------------------------------------------------------------------------- | ---------------------------------------- |
| 写入资格   | 手工／自动、pending／confirmed／disputed／interpretation、空来源、重复来源 | 模型只读合格事实；候选不自动升级         |
| 来源       | 当前／失效修订、撤销、助手问句只读语境、未展示尾段                         | 事实根为用户来源；引用真实且仍有效       |
| Unicode    | emoji、扩展汉字、组合字符、换行、代理对半截                                | UTF-16 端点合法，sliceHash 精确          |
| 时间       | 有效期前一毫秒／起点／终点、过期清理滞后、未来排队来源                     | 资格即时生效，不依赖 timer               |
| 主体与范围 | 用户／姐姐同主题、现实／虚构、旧 unspecified                               | 不串主体，不将计划视为发生               |
| 确认       | 四动作、重复／乱序／跨入口、旧 revision、拒绝后迟到提取                    | 幂等且无误删、无候选复活                 |
| 版本       | pending、展示、摘要、确认、索引 ready、事务回滚                            | 三版本分离；索引就绪不取消 Run           |
| 分流预算   | 1699/1700/1701/1999/2000/2001、重启、工具增长                              | 滞后稳定、完整工具组、总量合法           |
| 分段       | 首输入、30 分钟边界、有排队、重启、跨段                                    | 同 scope 一个 open 段，聊天不重跑        |
| 摘要       | 软触发、完整组、200 条后回问、失败／重试／迟到、删除禁重建                 | 只从原文生成，有覆盖和缺口标记           |
| 历史读取   | 最新两块以外摘要、日期、旧事件、无匹配                                     | 正确后端，有来源，不编造全量             |
| 来源展开   | 仅本 Run 授权来源、任意 ID、来源变化、展示前缀、分页                       | 未授权拒绝；单次受预算限制               |
| 向量       | 固定模型／前缀／维度／数值／归一化、缺模型、长文本                         | 严格验证，不静默截断长事实               |
| 一致性     | 新事实未索引、更正／遗忘期间编码、错模型、重启重建                         | 陈旧向量不水合；缺索引明确降级           |
| 队列       | 上限、同 bot 排队、超时／取消、坏协议、worker 退出                         | 调用者及时释放，迟到结果不进入聊天       |
| 扫描       | 常驻矩阵、不同 generation、过滤、25000 行                                  | 不逐查询复制整矩阵，不串 scope           |
| 迁移恢复   | v1→v2、迁移失败、迁移前备份、恢复最新删除清单                              | 事务原子、支持新版、不降低版本           |
| 删除闭包   | 只删摘要、原来源、事实、更正根、恢复旧备份                                 | 摘要、向量、依赖、缓存与导出不复活       |
| 交互       | 等待两档、取消／失败／切角色／刷新、确认卡片                               | 状态不是消息，不进 TTS 或记忆            |
| 语义召回   | 原题集＋独立主题、精确词／换说法／列举／长文头尾                           | 记录 recall、miss、候选和延迟            |
| 回答判断   | 已知／未知／否定／相同主题缺属性／冲突／计划                               | 真实模型原始答案、弃答、证据引用分别计分 |

发布边界：本轮继续在隔离库中测试迁移与编码，不用合成结果替代 MEM-G1 七天自然观察，也不自动批准正式库切换。实现与验证完成后，必须保留失败样本、未测设备与已知局限。

后续修复新增 `memory-query.test.ts`、`memory-scan.test.ts`、`memory-scale.test.ts`：通用问法、资格与缓存回滚；整块矩阵和穷举排序一致；25000 行的冷／热读取、取消与来源失效。强制性能门槛由 `npm run test:memory:performance` 执行，含 4 次 25000 行服务冷启动及全部后续样本；实际数字与初始化降级见[增量验收](memory-recall-latency-fix.md)。

五题答复复核新增 `memory-answer-score.test.ts`、`memory-answer-judge.test.ts`、`memory-delivery.test.ts`：冻结原答案旧分不变；同义与附加断言逐条有据；文本含义与测试自报布尔分开；坏协议、错引用、评审故障不放行；实际请求中的工具交付证据可参与评分；未交付缓存、伪造消息和截断文本不得扩大证据。真实模型另测未知兼任／技能及明确正向证据，见[五题复核](memory-answer-five-case-audit.md)。
