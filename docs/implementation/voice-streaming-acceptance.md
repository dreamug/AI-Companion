1. **HTTP Streaming**：一次 POST `/v1/tts` 请求，显式使用 `s1`、MP3、`latency: balanced`、`chunk_length: 100`。后台验证音频类型、跨块 MP3 头后立刻逐块转发，通过 Node Readable 保持背压；网页通过 MP3 MediaSource／SourceBuffer 逐块接收、解码和播放。文字回复仍先完整生成，不涉及文字 Token 分句或 WebSocket。
2. **准确音色**：「甜妹」，作者 `shi9444woyi334390`，ID `5b50d7ae59f24c0cb447599df8ae34ab`。官方模型详情 API 返回 200、trained、zh，与[官方音色页](https://fish.audio/app/m/5b50d7ae59f24c0cb447599df8ae34ab/)匹配。`env.local` 和代码默认值已同步，临时密钥保持不变。
3. **默认自动朗读**：每次打开页面默认开启，可取消勾选。首个快照先将历史标记为已见，之后仅朗读本页初始化后的、最近两分钟内最新一轮完整助手回复；刷新和 SSE 重连不补播历史。

[官方 HTTP TTS 协议](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech)提供当前参数。浏览器在运行时检查 MP3 MediaSource 支持；[MediaSource 文档](https://developer.mozilla.org/en-US/docs/Web/API/MediaSource/addSourceBuffer)明确存在兼容差异。支持不足时界面提示兼容模式，同一次请求收齐后播放，不再发起一次收费合成。浏览器禁止自动播放时保留本次音频和播放器，提示点击，开关保持开启；不循环重试合成。

新增门控测试具有确定性证据：提供方尾块尚未放行时，真实 HTTP 客户端已经收到首块；独立真实浏览器已推进播放时间且未暂停，证明网页没有等待整段下载。另覆盖跨块 MP3 标记、流中失败截断、客户端断开取消、自动播放权限拦截、兼容回退。沿用来源 ID／修订／epoch、遗忘清理、手动停止、刷新不重播和配置故障时文字聊天可用的回归用例。

完整浏览器回归发现离线渠道仍占配额：显式 offline 现在立即删除在线身份、释放槽位；关闭未知身份也不会抢占配额。测试明确导航离开以发送下线事件，不把浏览器测试进程的强制关闭当作可靠 pagehide。

## 生命周期和边界

- 首块前的失败仍返回安全 JSON。首块后的失败关闭并截断 HTTP，客户端显示失败，不在音频中附加 JSON，也不记为成功完整合成。
- 单并发、4000 字／10 MiB／45 秒限制不变。停止、新消息、遗忘、断开或服务退出会取消等待、关闭读取和释放播放器；来源正文未变的反馈更新不会中断朗读。
- Trace 只保存字符数、字节数、分块数、首块／总耗时、音色和模型等元数据。正常音频不落盘；固定合成诊断样本例外保留为 [试听](../../data/reports/voice-preview.mp3) 和本地 API 诊断音频，不含私人对话。
- 自动朗读会向 Fish Audio 发送新助手回复正文；不会发送整份上下文、记忆库或前端密钥。本地取消／遗忘不能撤回已外发内容或保证撤销提供方计费。
- 声音自然度、`balanced`／较短 chunk 对听感的影响、实际设备扬声器输出、后台／休眠与其他浏览器表现仍待个人使用验证。没有新增麦克风输入、语音识别或公网推送。

服务已重新构建运行于 `http://127.0.0.1:4317/`。刷新页面加载新脚本即可使用；如有未发送草稿，先保留草稿。参数和操作见[使用手册](runbook.md#fish-audio-语音朗读2026-10-23-增量)。
