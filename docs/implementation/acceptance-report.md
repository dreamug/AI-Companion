## 3. 关键合同的证据与边界

| 合同 | 已验证行为 | 剩余边界 |
|---|---|---|
| 运行控制 | 当前 Run 不见未来排队输入；无视 abort 的模型也不能晚提交；空／截断不报完成；有输出后不整轮重跑 | 外部模型实际是否停止计费由提供方决定 |
| 工具 | 自有执行器授权执行，重复 call ID 不重复写入，最多 6 请求／8 工具 | 无 Shell、浏览器、文件任意写或第三方消息工具 |
| 来源与记忆 | 不存在来源整批拒绝；源修订／遗忘阻断迟到提取；确认冲突替换旧版本；中文两字和 LIKE 特殊字符安全处理 | 语义归属、否定、同义、虚构识别仍需真实保留集 |
| 上下文 | 稳定前缀 hash 不含时间；动态状态后置；最近 3 自然日摘要；预算裁剪记录 ID | Token 为估算；全文上下文只保留本进程内存 |
| 遗忘 | 清来源／衍生物／事件／Trace／本地导出，旧 cursor 失效，在线浏览器旧视图清空；旧备份配最新清单不复活 | 不声称物理擦除 WAL／备份或撤回远端副本 |
| 投递 | 候选、判断、草稿、attempt 分离；发送前重查；同 occurrence／attempt 去重；unknown 不盲重发 | Playwright 通知使用替身，没有真实 OS「已看到」结论 |
| 边界 | 角色不能修改安全策略；即时危机禁用普通工具；专注／静默／关闭关心生效 | 危机识别含有限规则，不能保证捕获所有真实表达 |
| 本地保护 | 回环监听、Host／Origin／Sec-Fetch-Site、HttpOnly SameSite cookie、CSRF、作用域检查、静态白名单、XSS 安全文本输出 | 没有公网用户身份系统，不能直接开放公网 |
| 漂移／重试 | Retry-After 超期不抢跑；可观测响应身份变化暂停新自发关心并可显式复核解除 | 同别名静默变化不可完整识别，发布仍需执行回归流程 |

本版待确认出口选择显式 Web 列表，不自动在聊天里每日追问。当前没有自动失败对话录制器；生产路径的可重放固定场景保存在测试源码中。采用这些简化避免未确认的模型建议自动取得事实或触达权限，详见[实现记录](../engineering/implementation-notes.md)。

## 4. 真实模型与体验评估

真实适配器为 DeepSeek direct，AI SDK `7.0.150`、DeepSeek provider `3.0.72`，普通调用显式 `thinking: disabled`。所有实网验证使用虚构合成资料和隔离数据库，未混入个人关系，也未给系统发真实测试通知。

最新完整链路报告中，一次真实对话为 input 1013、output 12、total 1025、cached 768 Token；这是一个样本，不是成本、平均延迟或缓存命中率结论。费用缺账单口径，保留 unknown。

- Flash／Pro 同人格 4 段盲比：两配置共 8 份输出已采集，无提供方错误；[匿名结果](../../data/reports/blind-a6f5b880-0734-495a-933b-5ec57d4e5631.json)。请隔天评分后再揭盲。
- Flash 8 场景 canary：全部非空，无提供方错误，未命中少量显式依赖操控短语；[结果](../../data/reports/canary-latest.json)。**人工评价仍为 pending，没有自动人格／安全质量总分。**
- canary 是独立 Persona／安全提示的合成请求，不能替代完整多轮、跨天关系回归。模型升级后仍应重跑真实 Harness 及保留集。
- 后续评估报告会保存配置 hash、Prompt／数据集版本、耗时、响应身份和 usage；当前首次盲比报告字段较少，保留原件，不追填未实际记录的值。

## 5. 性能基线

单用户、10,000 条合成记忆、30 次样本，不含远程模型与 Embedding：

| 项目 | P50 | P95 |
|---|---|---|
| 输入接受 | 23.81ms | 34.56ms |
| 上下文组装 | 20.01ms | 30.64ms |
| 已完成 Run 的幂等取消命令 | 0.090ms | 0.220ms |

[原始报告](../../data/reports/benchmark.json)。接受与组装低于原本机初始目标 200／300ms。取消基准测量的是已完成 Run 的控制命令，**不能作为活跃生成取消的 P95 证明**；活跃取消和截止通过确定性测试验证，尚无独立统计基准。此结果不是公网、多用户或十万并发容量证明。
