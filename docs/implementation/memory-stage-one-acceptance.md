### 事实读取

资格必须同时满足 assertion、active、confirmed、非 interpretation、非空且有效来源、有效时间和现实域，并过滤比当前 Run 更晚的输入来源。全量探测按稳定 ID 分页读到 EOF，或在超过事实预算时停止；不以管理页的 500／2000 条上限冒充全量。

普通查询保留并标注旧 unspecified 事实；明确询问现实／线下经历或履历时排除 unspecified。已标为 roleplay 的记录不进入 reality 域，反向亦然；排队 Run 采用自身人格域快照。生产实现未增加完整的语义意图分类器。

分流按默认域合格事实的完整投影计算，独立于查询、日摘要和当前 Run 的队列截点。all 超过 2000 才进入 hybrid 状态，hybrid 到 1700 或以下才返回 all。状态写入 Settings.memoryReadState。尚未接向量，因此 hybrid 状态的实际读取结果是 keyword／degraded，携带 semantic_not_enabled；绝不报告混合检索已成功。预算裁剪后实际 mode=budget_limited，complete=false，持久分流状态不变。

首次上下文和 search_memory 复用资格与事实投影；工具结果额外受 1000 token 节选限制。检索不完整的说明提供给回答模型，空结果不证明用户从未说过。超过单块预算的长事实／日摘要整条退出；片段化与 read_memory_source 尚未实施，不把 MEM-T09 的完整长片段能力算作本阶段通过。

### 预算与近期窗口

已落地：系统最终串 7000、明确边界 1600、事实 2000、日摘要 500、近期原文 4000／最多 24 条、确认跟进 500／最多 6 条、工具交换目标 2000、完整输入上限 24000。最终检查包含消息和 JSON 包装、当前输入、工具 Schema。2000 token 当前输入只是方案中的常规预算示例，未把原有 12000 字符输入限制另行收紧。

超过总量时，依次退出日摘要、跟进、旧闭合工具交换、最旧完整 Run、事实；块已低于台阶时跳过。MEM-3 的对话摘要块尚不存在，不伪造该裁剪台阶。工具调用与对应结果整组保留，最新活跃组不拆开；超过工具块目标时登记 activeToolException，并按总预算继续裁剪可选块。必选项装不下则在下一次模型请求前明确失败。

每个模型 Step 更新投影和预算 Trace；来源原文不被裁剪改写。助手历史只使用已展示的 UTF-16 前缀，去掉可能悬空的高代理项。未展示回复使用未确认展示的说明。

### 确认与幂等

卡片为管理控件，位于消息流外，不形成 Message、TTS 输入或确认事实。来源可展开，长候选可查看完整内容；文本使用 textContent。实际显示由可见页面中的 IntersectionObserver 回执，不把快照读取或服务端预留当成阅读证明。

后台准备卡片只发生在领域处理边界，快照纯读取。非明确保存请求须有 topic／关键词交集，每 bot 每个用户自然日最多预留一张主动卡片；离线预留也可能消耗当天配额，这是保守去重策略，不会记为实际展示。明确请求保存的当前来源目标不占主动配额。同一 bot 同时一张；专注、免打扰、危机和 queued／running 状态隐藏，发送分条期间亦隐藏。暂缓后不再次主动推荐该候选，可在维护页继续处理。

命令复查作用域、expectedRevision、来源与有效期。确认不改候选 origin；更正后新事实与原候选共用根 ID 进行漏斗去重。同一修订、相同操作的最新回执可跨两个入口和重启重放；同 key 不同参数拒绝。旧操作在后续不同决策后可能返回 revision_conflict，不重复执行副作用。单独发送“对”不会自动确认。

pending 的“不保存”只清空该候选正文、结束候选并记录 discarded，不删除原始发言、不增加 epoch、不取消无关 Run。同来源、同修订、同正文的迟到提取／工具重试通过拒绝摘要哈希去重；新用户来源可以重新表达。哈希仍是关联个人数据，明确遗忘同事务清除；首期不承诺不同措辞的语义判重。明确遗忘仍走现有删除台账，并清除关联根／修订的 lifecycle 和当前卡片引用。过期、超量和失效来源分别记录退出原因。关联 lifecycle 批量清除不重写无变化的 FTS 条目，十万条 fixture 的删除验证约 2 秒内完成。

## 2 指标使用

服务端配置 `HARNESS_TRAFFIC_ORIGIN=natural|synthetic|unknown`。mock 默认 synthetic，真实提供方未显式配置时默认 unknown，防止把未知来源误认自然使用。请求体不能覆盖该字段；旧记录继续 unknown。准备正式观察时，需在自然使用的服务环境显式设置 natural，并将合成测试保持 synthetic。

受保护接口：

- `GET /v1/memory/metrics?traffic=natural`：当前角色的指标，不带正文；省略 traffic 表示 all。
- `POST /v1/memory/:id/exposure`：需匹配当前 offerId，只表示客户端报告显示。
- `POST /v1/memory/corrections`：共用确认命令，支持可选 idempotencyKey。

只读命令示例：

```sh
npm run memory:metrics -- --data-dir /absolute/path/to/data --traffic natural
```

CLI 不调用 Store、恢复或迁移逻辑，使用 readonly 连接，按 manifest 中未归档 bot 汇总。读取生命周期、状态、期限、时区与输入计数所需字段，不输出消息／事实正文。只支持当前 v1 schema，其他版本报告 unsupported_schema，不降低版本。

报表给出生产、机会、显示、确认、修正、暂缓、丢弃、过期、超量、失效来源、待处理年龄、cohort 和分子分母。机会指在领域边界实际进入资格／相关性选择的输入与候选组合，同一输入去重；已有待处理卡片时不新增选择机会，机会不代表通过配额或已经展示。人工直接录入与自动候选分开；更正产生的修订不算第二次生产。未满 7 天的样本不进入成熟分母。natural 少于 10 个实际展示或没有成熟 cohort 时，各比例为空并标样本不足；达到条件只给 review_required，不自动放行下一阶段。

统计范围为仍保留的、已埋点记录及输入，绝非历史全量。遗忘后不反推已清除的身份／生命周期，censoredCount 为未知；旧库缺失信息仍沿用[只读基线报告](../research/memory-confirmation-baseline-2026-10-24.md)的“不可识别”结论。
