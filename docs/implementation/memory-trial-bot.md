## 试聊

第一次打开，阅读并点击「我了解外发范围，开始使用」。可直接说「我平时喜欢喝红茶，帮我记住」，候选出现后点击「记住」，再换一种问法询问偏好。自动整理只产生待确认建议；候选也能在记忆面板里确认、更正或移除。

试用从空白聊天和空白记忆开始，未复制正式 bot 的人格、消息或记忆。刷新、关闭页面和正常重启服务不会清空试用数据。浏览器的「整理记忆建议」默认开启，「主动关心」初始关闭。

## 运行边界

| 项目 | 当前设置 |
| --- | --- |
| 入口 | `http://127.0.0.1:4321/`，仅监听本机 |
| 数据目录 | 项目下 `local-data/memory-trial/`，已加入忽略列表 |
| 角色 | 单个「小野·记忆试用」 |
| 模型 | 现有环境配置的 DeepSeek，当前为 `deepseek-flash` |
| 新版记忆与摘要 | 开启，仅初始化试用数据库至 schema v2 |
| 向量检索 | 仅本试用开启离线 E5；小库全量、超预算后混合；见最新发布记录 |
| 记忆回答推理选项 | 仅试用实例开启；有已选记忆时生效，沿用既有 Run 限额 |
| 正式库与正式配置 | 未迁移、未修改，正式实例未重启 |

试用沿用项目的正常 Web、Harness、模型适配器、提取与确认链路，不使用 benchmark 的 JSON 回答协议、预置事实或替身模型。读取现有 `env.local` 中的提供方配置，不复制正式角色的 BYOK 文件；以后在试用页保存的 Key 也只进入试用目录。

入口由 `scripts/memory-trial.ts` 固定端口、数据目录和记忆开关，避免继承正式服务的 `PORT`、`HARNESS_DATA_DIR` 或向量开关。数据目录不允许符号链接；实例锁阻止重复打开同一个试用库。

## 停止与再次启动

当前实例在后台运行，关闭网页不会停止后台。进程信息保存在试用目录的 `daemon.lock` 和 `trial-status.json`。停止时，先核对锁中的 PID 属于该试用实例，再向该 PID 发送 SIGTERM。不要停止正式服务的进程。

停止后，在项目根目录运行：

```sh
npm run memory:trial
```

这条命令使用原试用数据；已有实例时不要重复启动。它不是开机自启任务，电脑重启后需再次启动。
