## 本版决策

- 当前事件的自然同意只授权该事件，不自动开启关系级related_events；自然征询每关系最多实际展示一次，拒绝/跳过不反复问。
- 受限私人事件按原子内容分类，情绪强烈不自动升级；合法最小事件可在受限用途下复用本地E5，间接候选不证明因果或允许主动披露。
- 明确允许关心某件事可复用交互偏好授予该对象主动用途，仍受场景、频率和撤回约束。
- 观察只基于有期限的reported历史事件，不另建观察库或扫描原聊天；状态到期和历史证据保留分开。
- 交流段复用现有严格超过30分钟且无其他在途Run的规则；实际主动问过即进入冷却，不增加转题分类器。
- 人格故障文案可预审固定配置；风险分级发布保持默认关闭的独立实验，不以温度或延迟抵消真实性错误。

## 工程范围与版本

这是记忆领域加必需的Agent执行适配：上下文、检索、事务、发布、取消和有限恢复；不重写通用Agent内核，不新增情绪状态机、授权服务、关心Agent或外部向量数据库。SQLite仍是权威记录，MD为派生导出，本地E5沿用现有固定模型。

三份文档职责分开；示例用于验收而非生产题目分支。分类和授权语义以产品规则为准，执行和数值以工程合同为准，早期范围以清单为准；若发现冲突，先修正文档，不挑宽松条款实施。
