# CM3 2 最小试聊清单

版本：3.4 冻结基线。状态：CM3 0至2最小切片已实施，新隔离入口4331可试聊；7天自然观察尚未完成。

实际验证和限制见[切片交付记录](../implementation/companion-memory-cm3-2-release.md)。这不是完整v3.4验收。

目的：完成最小可信链路后尽早真实试聊，不等全部温度层、检索维护和管理页完工。只开新隔离副本，不替换4321或正式bot。本清单唯一维护早期范围与放行条件；[产品规则](companion-memory-v3-product-rules.md)定义行为，[工程合同](companion-memory-v3-engineering-contract.md)定义执行和完整验收。本轮仅按本清单实施，新开隔离副本；现有服务不变。

## 1 本次切片做什么

| 必须交付                 | 可见结果与证明                                                    |
| ------------------------ | ----------------------------------------------------------------- |
| 低风险普通信息自动形成   | 无逐条确认卡片；真实输入经inbox/提取/commit，非手工种入confirmed  |
| 长期/临时称呼及禁用称呼  | 当轮遵守，下一轮与重启后读有效值；临时范围结束恢复长期值          |
| 明确保存、更正、遗忘     | 真实提交才确认，失败/partial/临时范围不夸大；不再次征求同一意愿   |

允许先沿用完整现有发布检查方式，普通快路/并发优化随后完成。关键事务真实性、来源资格、取消与遗忘不能以“早期”名义后置。现有组件能满足即复用，不为切片新建通用调度/权限框架。

## 2 本次明确不做

- 不开放受限私人事件的首次征询、自动形成、主动关心或受限E5用途；不把未支持能力展示为可用。
- 不开放跨次观察、广泛bot自述学习、共同仪式自动形成和主动接续；后续按独立能力验收逐项打开；v3.4主动发起交流也不在本切片开放。
- 不要求每日整理、完整MD界面、完整历史事件E5、全部冻结位置或全部压力负载先完成。
- 不采用风险分级发布或未经检查的流式输出，不新加情绪状态机、观察库、关心Agent或向量服务。
- 不修改现有4321聊天/记忆，不迁移正式库，不改变任何正式向量开关；不自动将副本新聊天合并回源bot。

新副本保持主动发送关闭（proactiveEnabled=false），本次从空库建立、不复制源资料；未来若复制FollowUp/Series，只作历史：在新副本将未授权实例/系列置为cancelled并注明不继承触达许可，既有状态值即可，不自动续排或补发；源bot设置不变。普通E5只保持新副本明确继承的既有设置；当前切片主要证明提交和结构化读取，不以接向量作为可试聊前提。未开放功能的旧数据不能绕过资格过滤提前参与模型上下文。

## 4 怎样开始与怎样收反馈

本次已按明确授权创建新的4331入口（空库起步，保留合成演示记录）。浏览器说明“这是新隔离副本，现有bot仍保留”，列出本清单可用/未开放能力及备份/回退路径。只更新该副本；source bot不因新增入口而停机或换开关。

从真实使用开始观察至少7个自然日，争取30个用户实质回合；不足则说明数据不足，不强迫补聊。反馈只需可选笔记或标记：被记得、像客服、被打扰/被监视、说错了。记录具体片段与当时实际依据，不要求每轮打分，不自动创建提醒或通知。

每轮迭代优先复核失败与正向片段，决定接下来先做快路、跨天接续还是其他能力。尚未开放的受限事件等只能用合成片段验证分类/授权口径，不拿早期试聊声称其召回有效。新增温度能力须再收其真实反馈，不能借前面7天直接通过。

## 5 何时扩大范围

先冻结产品分类、事件级许可和评分口径，再运行相应能力的开发/未运行集。受限事件需完成明确/间接回指、泛化多因、无答案、主动许可/撤回与遗忘对照；观察需证明两日独立reported证据可读且到期不误用。通过哪项才开放哪项。

完整稳定交付仍按工程合同的核心72位置、温度48位置及负载；触达独立轨道另验收，不阻塞记忆交付和人工验收执行。更新既有4321必须另满足完整门槛及实施授权；早期副本新聊天单独保全，不承诺无损合并。本清单不构成后续修改既有bot或正式数据库的许可。
