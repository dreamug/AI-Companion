# 专家评审的采纳与修正

v0.3 · 2026-10-23 · 开工前勘误后冻结。认知状态：以下为评审取舍与文档变更，未实现；数字为初始参数或估算，非结果。M0期间只登记[实现偏差](implementation-notes.md)，冲突按[权威规则](../../README.md#文档冻结与权威规则)处理。

核心采纳：把“是否愿意每天相处”的验证移到第一周，工程加固随后持续跟进。保留有价值的正确性合同，缩小它们在第一版的实现范围。

## 三处需要保留的事实区分

**Letta 的语言与引入价值。** 此前检查的是 Letta Code 的 TypeScript 本地 Backend，不能概括为必然引入 Python。取消实验仍然合理，因为我们不采用它的核心记忆工作流，适配剩余执行器的收益有限。[固定版本证据L5](../research/source-evidence.md#l5--letta-ailetta-code)

**系统通知与阅读回执。** 操作系统接收通知、用户点击和用户看见不是同一个状态；点击也不是完整阅读的证明。没有点击不能记成拒绝或自动重发。试用时通过可跳过的主动反馈补充曝光与偏好标签。

**版本固定与漂移检测。** DeepSeek当日文档用 `deepseek-flash` 标识服务，说明底层为 DeepSeek-V4.1-Flash-1017；没有据此证明该底层字符串就是可调用的不可变ID。选择可用别名，同时保留映射记录、回归和漂移观测。[官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)

## 第二轮评审：开工前勘误

| 意见 | 决定与落点 |
|---|---|
| 浏览器通知替代原生通知桥接 | 采纳。Trace标签常驻，用户手势授权，onclick回执；移除外部IM备选，常关闭标签才考虑极薄Electron托盘 |
| 页面关闭与系统压制需分开 | 已知离线为unavailable＋not_attempted；连接不明为channel_unknown；已尝试但系统是否显示不明为曝光unknown。回来只看站内历史，不补弹旧通知 |
| M0接口过多 | 采纳两档：6条正式路由，其余共用一个本地维护入口。完整runner、自动canary、抽取工具循环与通用命令平台后置 |
| Trace直接改数据行 | 采纳手工选行填值，不采纳绕过用例直接SQL。维护更正／遗忘仍校验修订、取消迟到结果并留下禁重建标记；保持删除后不恢复 |
| 摘要选择与补算缺失 | 最近3个已结束自然日＋手工置顶，固定顺序与2000 token记忆块；启动／跨日后最多补最近一个有消息的已结束日，不批量补天 |
| 总工期偏乐观 | 撤回旧总人日与6–10周锚点。M0的3–5人日只作首个时间盒，M0／M1后分别按实际编码、调试和测试重估 |
| 第二模型与数据条款 | 首周做3–5片段小盲比，默认同提供方Pro候选，不写入记忆或发通知；3.3已记录官方条款、适用范围与API留存／训练待确认项 |
| 危机回应仍应熟悉 | S02加入同一角色的认真语气、允许称呼和熟悉感人工评价，不以陌生客服模板替代安全回应 |
| W1合规与年龄 | 增加两项启动审查，覆盖目标地区、拟人化互动、数据地域、年龄／亲密边界与应急需求；本轮不实现 |
| 冻结与权威 | 保留v0.3，统一开头认知声明；README定义领域、实际接口与已启用验收的权威规则；M0只维护偏差记录 |

以上勘误完成后冻结，不继续发散为新一轮架构设计。第二模型盲比及其实际效果、浏览器权限／点击能力、模型费用均在实施时验证。

## 最终讨论补充

| 最终决定 | 文档落实 |
|---|---|
| 后续做网页产品，现在不动正式前端 | 主方案2、16、17；规模路线W1；个人版通过后再启动网页 |
| 保留TS，Harness自己写 | 技术决策明确选型理由、Python重新评估条件与领域职责 |
| AI SDK只做可替换模型接入 | 自有执行器控制Step、权限、预算、取消和提交；接口文档定义不依赖SDK的数据格式 |
| 未来可能十万级用户 | 分开注册、日活、在线和同时生成；保留TS，不原样扩大SQLite；W1–W3独立验收 |
| 首版不为规模过度设计 | 只保留owner／relationship作用域、端口、幂等和版本；账号系统、PostgreSQL与租约后置 |
| 网页需要可靠续传与权限边界 | M1公开stream_events与诊断Trace分开，失效cursor重取快照，正文遵循遗忘；普通网页不读内部Trace |

本轮还修正了两个容易遗漏的迁移点：单Run约束按关系而非共享角色模板；共享数据库中新实例不能把其他活实例的running任务一律标中断。均已写入主方案、规模路线与后置验收。
