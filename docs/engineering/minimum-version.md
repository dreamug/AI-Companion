# 如果只做一个最小版本

v0.3 · 2026-10-23 · 开工前勘误后冻结。认知状态：设计基线，未实现；数字为初始参数或估算，非测试结果。M0期间记录[实现偏差](implementation-notes.md)，复盘修订；冲突按[权威规则](../../README.md#文档冻结与权威规则)处理。

技术基线：TS自研Harness与有界执行器，AI SDK Core只做可替换模型接入；DeepSeek、SQLite个人单实例。owner／关系是明确字段，不先做账号、通用命令平台或分布式设施。

## 首周就交付

| 必须有 | 最小做法 |
|---|---|
| 真实对话 | Flash非思考、固定人格、简单Trace页；保存消息，能停止 |
| 可检查记忆 | 最近3个已结束自然日的有效摘要＋手动置顶确认记忆，固定顺序；记忆块初始2000 token，优先边界／置顶，超限先移除最旧摘要 |
| 每日摘要 | 启动或跨日后首次输入时，最多补最近一个有消息的已结束日；不补全部漏天；源修订／遗忘检查，手动删后不自动重建 |
| 工作共处 | 专注、免打扰、关闭主动关心；不自动看屏幕，不为空闲持续调模型 |
| 真实关心 | 手工建立一次性跟进；Trace固定标签常驻，浏览器Notification，用户点击授权；离线不尝试，回来只看站内历史 |
| 最小Trace | 聊天／停止、配置、摘要源、状态开关、投递状态、必要日志与一份维护表单 |
| 必须保护 | 凭据在后台、安全小集、来源与删除版本、取消迟到保护、unknown不盲重发 |

浏览器构造／show不证明被看到，onclick只记点击；macOS专注压制与实际曝光可为unknown。首周只评价在电脑前的体验，离机触达留到App。常关闭标签时才评估极薄Electron托盘适配，只连SSE、通知和点击，不含产品UI，也不是M0默认任务。

## 接口只做两档

- **正式API：**输入、取消、快照、SSE、状态开关、投递attempt与必要回执。Run和投递查询合入快照，共6条路由。
- **手工维护：**摘要更正／删除、遗忘、确认记忆置顶、跟进创建／取消、曝光／偏好反馈，共用一份本地表单和维护入口，不逐项开发资源API。

手工指手工选行填值，不指绕过领域用例直接改SQLite。删除／更正仍检查修订，真正遗忘来源要使相关摘要和待发内容失效，拒绝迟到计算；删除派生摘要则留下禁重建标记。详细规则见[接口两档](api-and-runtime-contracts.md#3-冻结的-http-v1-接口与m0两档范围)和[日摘要规则](harness-engineering-plan.md#7-记忆从证据到可更新的共同经历)。

M0从消息快照恢复；M1再做持久事件cursor。模型调用不自动执行领域副作用。首周人格／安全用例先手动复评，不建设完整runner、故障注入平台或每日canary系统。

## 先砍这些

- Letta接入、默认AIRI实验、外部IM、Node原生通知桥接。
- 图／独立向量库、Embedding调优、原生中文分词扩展和自动记忆抽取工具循环。
- 每种记忆一张表、通用审批／命令框架、多Worker租约和数据库集群。
- 自动情绪画像、亲密度分数、无尽反思、多Agent、自动屏幕感知。
- 正式网页／桌面UI、Live2D、语音、角色市场、App、多设备和多用户。
- 一次标完200条事实、完整Trace看板、完整故障Fixture录制回放。

## 第3天和第7天复盘

1. 愿不愿意回来找它？人格最稳和最不像的具体片段是什么？
2. 最想让它记住什么？哪次回忆多余或缺失？
3. 通知是喜欢、打扰、没看到，还是渠道本就离线？是否想关闭？
4. 实际编码、调试与测试各花多久？哪些工作超出首周范围？

首周做一次3–5片段、同Persona／上下文、隐藏模型名、隔天复评的小盲比；默认第二候选为同提供方deepseek-v4-pro，不新增外部账号。只用合成／去标识片段，结果不写记忆、不触发通知；可用性或预算不足记录缺项。提供方条款检查见[主方案3.3](harness-engineering-plan.md#33-deepseek-首次接入)。

## 时间盒与后续

首个开发时间盒3–5人日，随后至少7自然日使用；超出就记录实际原因、调整范围，不删保护赶工。旧24–37／29–48人日和6–10周不再作为排期依据。M0结束重估M1，M1结束重估后续；M5保留14自然日稳定观察，网页与扩容另估。
